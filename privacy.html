Privacy Policy

Last updated: November 17, 2026

This policy describes the privacy practices for this personal rclone Google Drive configuration and its informational website.

1. Google User Data Access

The rclone software, when configured by the account owner, accesses Google Drive files, file metadata, and supported Google documents through the Google Drive API. Access is authorized by the account owner using Google OAuth 2.0.

2. How Data Is Used

Google user data is used only to provide the file listing, viewing, uploading, downloading, and management operations explicitly requested by the account owner through rclone.

3. Data Storage

rclone runs locally on the account owner's Windows computer. OAuth tokens and configuration settings are stored in the local rclone configuration file. File contents may be temporarily cached on the local computer depending on the rclone settings.

This informational website does not operate a server that receives or stores Google Drive file contents or OAuth tokens.

4. Data Sharing

The account owner does not provide Google Drive contents or OAuth tokens to this website or its operator. Data is transmitted to Google as necessary for the Google Drive API operations requested by the account owner.

5. Security

The account owner is responsible for protecting their Windows computer, rclone configuration file, OAuth credentials, and local cached files.

6. Data Retention and Deletion

The account owner can remove local rclone configuration files and cached data from their computer. Access authorization can also be revoked through their Google Account security settings.

7. Third-Party Services

This website is hosted by GitHub Pages. Google Drive API services are provided by Google. Their respective privacy policies and terms apply to their services.

8. Google API Services User Data Policy

Use of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

9. Contact

For questions about this personal configuration, please contact the repository owner through GitHub .

This is an independent personal configuration and is not an official Google product.
