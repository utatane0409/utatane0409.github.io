Personal rclone Drive Access

This is a personal-use configuration of rclone for accessing Google Drive from a Windows computer.

Purpose

This setup allows the account owner to access their own Google Drive files through rclone. Files can be viewed, uploaded, downloaded, and managed using a virtual drive on Windows.

How it works

The application runs locally on the owner's computer. It communicates directly with Google Drive using the Google Drive API and OAuth 2.0 authentication. No application server operated by the owner processes or stores Google Drive file contents.
